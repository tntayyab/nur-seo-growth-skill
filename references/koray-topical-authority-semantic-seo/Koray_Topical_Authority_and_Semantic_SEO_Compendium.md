## 🎯 1. FUNDAMENTAL PHILOSOPHY & MATHEMATICAL FORMULAS

Search engines are **Information Retrieval (IR)** and **Information Extraction (IE)** systems that optimize for:
1. **Cost of Retrieval:** How computationally cheap it is for a crawler to understand and rank your document.
2. **Information Gain:** Unique, verifiable factual value added beyond existing documents in the index.
3. **Semantic Relevance & Precision:** Strict alignment of entities, attributes, and predicates without contextual noise.

### 🧮 The Core Topical Authority Formula:
$$\text{Topical Authority} = \text{Topical Coverage} \times \text{Historical Data}$$

- **Topical Coverage:** Complete ontological coverage of all entities, attributes, and relationships within a niche knowledge graph.
- **Historical Data:** Quality session logs, user query satisfaction, direct visits, click satisfaction (no pogo-sticking), and domain crawl trust over time.

## 🏛️ 2. THE THREE FOUNDATIONAL PILLARS OF A TOPICAL MAP

1. **Central Entity (CE):**
   - The primary root entity around which the entire domain revolves.
   - Example: For an auto authority site, the central entity is `Automobile / Vehicle Maintenance`.
   - The central entity donates its attributes to all sub-clusters.

2. **Source Context (SC):**
   - The reason for the website's existence and its conversion model (Commercial, Affiliate, SaaS, Educational, News).
   - Prevents traffic-chasing drift into irrelevant entities.
   - Example: If the source context is *Automotive Repair Guides*, do not write about *Car Insurance Discounts* unless tied directly to repair costs.

3. **Central Search Intent (CSI):**
   - $$\text{Central Search Intent} = \text{Central Entity} + \text{Source Context}$$
   - The overarching intent that bridges user needs with website monetization and authority.

## 🗺️ 3. TOPICAL MAP ARCHITECTURE: MACRO VS. MICRO CONTEXT

### Macro-Context (Site & Section Level)
- Represents the broad thematic knowledge domain.
- Each URL must be assigned strictly to **one Macro-Context**.
- Core sections divide the Central Entity into primary attributes (e.g., *Engine Diagnostics*, *Braking Systems*, *Transmission Maintenance*).

### Micro-Context (Page, Section & Paragraph Level)
- The hyper-specific query answering node.
- Every paragraph must operate within a single Micro-Context.
- Sentences must follow strict predicate-argument structures: `[Subject/Entity] -> [Predicate/Action] -> [Object/Attribute Value]`.

## ✍️ 4. KORAY'S STRICT SEMANTIC CONTENT WRITING RULES

1. **Absolute Prohibition of Hedging Verbs (Zero Uncertainty):**
   - ❌ Never use: *might, could, should, maybe, seems like, perhaps, need to consider*.
   - ✅ Always use declarative, factual statements: *"The sensor triggers error code P0300 when ignition fails."*
2. **Immediate First-Sentence Answer (Inverted Pyramid):**
   - Every Heading (H2/H3) framed as a question MUST have its direct, definitive answer in the **very first sentence** directly underneath.
   - Fluff and introductory filler sentences are strictly forbidden.
3. **Contextless Word Elimination:**
   - Remove words that add zero contextual vector value (e.g., *"In today's fast-paced world"*, *"It is important to remember that"*).
   - If a sentence can be deleted without losing factual information, delete it.
4. **Entity-Attribute-Value (EAV) Density:**
   - Mention core entities with their precise technical attributes and numerical values (e.g., torque specs, temperature thresholds, code numbers).
5. **Linear Contextual Flow:**
   - Heading order must follow logical real-world sequences (Definition -> Symptoms -> Causes -> Diagnosis -> Step-by-Step Resolution -> Prevention).
   - Never jump between unrelated micro-contexts.

## 🔗 5. SEMANTIC INTERNAL LINKING PROTOCOLS

1. **Contextual Directionality:**
   - Links must flow from broader (parent) topics to specific (child) topics, and vice-versa within the same cluster.
   - Never cross-link between unrelated clusters without a clear bridging entity.
2. **Exact Anchor Text Precision:**
   - Anchor texts must explicitly name the target entity and attribute.
   - Generic anchors (*"click here"*, *"read more"*, *"this guide"*) are strictly prohibited.
3. **First-Link Priority:**
   - The first internal link in a document carries the strongest semantic weight for that context. Place the most important parent/sibling link early.
